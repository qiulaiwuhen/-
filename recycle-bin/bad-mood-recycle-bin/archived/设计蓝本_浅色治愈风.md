# 坏情绪回收站 · 浅色治愈风重做 · 开发蓝本

> 本文档是「把现有深色科幻小程序整体改为浅色治愈风」的设计交付物之一（与 `preview_light_v1.html` 配套）。
> 目标：沿用现有**业务逻辑与交互**（投放→铸徽章→不可转让数字资产→兑商家积分），仅替换**视觉语言**为暖米色 + 鼠尾草绿、圆角白卡、明亮治愈的基调。
> 交付物：可点击设计稿 `preview_light_v1.html` + 本蓝本。实际 WXML/WXSS 由开发同学据此实现。

---

## 0. 范围说明（务必先读）

| 保留 | 重做 | 丢弃 |
|---|---|---|
| 全部 JS 业务逻辑（机器人状态机、养分计数、徽章铸造、兑换核销、本地存储） | 所有视觉层（颜色/字体/圆角/投影/插画风格） | 深色背景 `#1a1f26`、霓虹青绿、3D 电弧、科幻宝箱面板 |
| 页面信息架构（首页主场景 / 投放输入 / 回收成功 / 我的-数字资产 / 兑换 / 记录） | 机器人 Nova 立绘（改为浅色圆润版，见 §5.1） | `app.wxss` 里的 `conic-gradient` 光晕、网格扫描底纹 |
| 徽章「数字藏品·不可转让」的文案口径与法律免责 | 徽章视觉（3D 电弧金属 → 柔和色环勋章，见 §5.4） | 暗色遮罩弹窗风格 |

**核心原则**：功能不动，皮肤全换。不要因为改色而改动 `pages/index/index.js` 的数据流。

## 3. 通用组件规格

### 3.1 卡片 Card
- 背景 `--card`，圆角 `--r-lg`，内距 36rpx，投影 `--shadow`。
- 浅底卡 `.card-soft`：背景 `--card-soft`，用于输入框、列表项底色。

### 3.2 按钮 Button
- 主按钮 `.btn-primary`：圆角 999rpx，高 104rpx，渐变 `linear-gradient(135deg,#A8BCAE,#8AA294)`，白字，投影 `0 8rpx 18rpx rgba(122,144,130,.35)`。
- 强调按钮 `.btn-accent`：渐变 `linear-gradient(135deg,#F0AE92,#E2886A)`，用于「去兑换/养分」等行动点。
- 禁用态：opacity .45（原 `.confirm-btn--empty` 逻辑保留，仅改色）。

### 3.3 底部 Tab Bar
- 高度 `calc(128rpx + safe-area)`，白底 92% 透明 + `backdrop-filter:blur(28rpx)`，顶边 `--line`。
- 选中色 `--primary-deep`，未选 `--text-3`。图标用 emoji 即可（🏠/📜/🌿）。

### 3.4 底部弹层 Sheet（投放输入）
- 圆角 `56rpx 56rpx 0 0`，白底，上滑 `translateY` 过渡（沿用原 `.panel` 的 `.38s cubic-bezier(.22,.9,.3,1)`）。
- 顶部 handle 横条 `--line`，宽 80rpx 高 10rpx。
- 遮罩 `rgba(61,58,52,.35)`（原 `rgba(6,8,11,.6)` 改浅）。

### 3.5 勋章 Medal / 徽章
- 圆形 `aspect-ratio:1`，色环 `box-shadow: inset 0 0 0 6rpx currentColor`，底色 `var(--emo-*) + opacity .18`。
- 选中态（兑换页）：`border:4rpx solid var(--primary)` + 背景 `--primary-soft` + 右上角对勾。
- **去掉** 原 `badge_particle_core_spec.md` 的 3D 电弧/金属质感，改为扁平柔色环（性能更好、风格统一）。如仍想要"高级感"，可在成功页用 CSS `radial-gradient` 柔光替代电弧。

## 4. 各页面布局结构与交互（WXML 骨架 + 说明）

### 4.1 首页 / 主场景（`pages/index`）
- 结构：`.scene`(柔色渐变背景 + 底部柔和丘陵 `.hill` + 飘云) → `.asset-hud`(右上角养分角标，原 chest-hud 改浅) → `.scene-copy`(顶部 slogan) → `.nova-wrap`(浅色 Nova SVG，点击触发输入) → `.tap-hint`(脉冲提示)。
- 交互：**保持原状态机**（`busy/moving/attentive/greeting/shaking`），但动画配色全换浅色；机器人立绘替换为 §5.1 的浅色版 SVG/PNG。
- 回收成功反馈：原 `.reward-bubble` 暗绿气泡 → 改为独立 `.success` 全屏覆盖层（暖底 + 柔光 + 徽章奖励卡，见 `preview_light_v1`）。

### 4.2 投放输入（`pages/index` 内 Sheet）
- 结构：`.sheet-head`(mini Nova + 引导语) → `.input-box`(textarea，placeholder 同原) → `.mood-row`(6 个情绪快捷标签，色用 `--emo-*`) → `.voice`(录音按钮，_REC 态用 `--primary-soft`) → `.btn-primary` 确认回收。
- 数据：原 `onInput / onVoiceStart / onSubmit` 逻辑不变。

### 4.3 回收成功（覆盖层）
- 结构：`.glow`(柔光圆) + Nova 立绘 + 文案 + `.badge-card`(勋章 + "获得专属徽章·已存入数字资产 / 永久保存·不可买卖转让") + 养分弹出。
- 按钮：「看看我的徽章」→ 我的页；「继续回收」→ 回首页。

### 4.4 我的 / 数字资产（`pages/mine`，需新增页面）
- 结构：`.profile`(头像+昵称+回收次数) → `.points-card`(养分余额 + 去兑换) → `.stats`(3 项统计) → `.wall`(徽章墙 3 列网格，锁定态置灰) → `.note`(不可转让说明)。
- 徽章墙点击 → 原 `.badge-mask` 弹窗，**改浅色**（深空底 → 白卡 + 柔色环）。

### 4.5 兑换商家积分（`pages/redeem`，需新增页面）
- 结构：`.redeem-tip`(1徽章=100分) → `.badge-grid`(可选徽章，多选) → `.merchant`(3 个合作商家权益) → `.summary`(吸底汇总：已选 N 枚·可兑 N×100 分 + 确认兑换)。
- 交互：选徽章实时算分；确认后弹 Toast「已兑换 N 积分」。**兑换后该徽章从资产墙移出**（原逻辑保留）。

### 4.6 回收记录（`pages/record`，需新增页面）
- 结构：列表 `.rec`(情绪色圆点 + 文案 + 时间 + 养分 + 徽章编号)，数据复用原 `reward` 流。

> 新增页面记得在 `app.json` 的 `pages` 数组补 `"pages/mine/index"`、`"pages/redeem/index"`、`"pages/record/index"`。

## 5. 关键视觉资产替换

### 5.1 Nova 机器人（浅色版）
- 形状：圆角矩形头身、鼠尾草绿描边 `#94A89A`、暖米色填充 `#FBF8F2`、暖橙天线灯 `#E89B7D`、柔粉腮红。
- 交付：`preview_light_v1.html` 内联 SVG 可直接导出为 `images/nova_light.svg`；或重绘 PNG 序列（busy/front/scratch/wink）替换原 `robot_*.png`。
- 背景：删除 `bg_scrap.jpg`（黄昏垃圾场），改用 CSS 渐变 + 丘陵 + 云，无需位图。

### 5.2 养分角标 / 宝箱入口
- 原 `.chest-hud`(右下角宝箱图标) → 改为右上角 `.asset-hud` 浅色胶囊（🌿 + 养分数字），点击进「我的」。

### 5.3 回收成功气泡
- 原暗绿 `.reward-bubble` → 全屏浅色 `.success` 覆盖层，避免深色突兀。

### 5.4 徽章视觉
- 原 3D 电弧金属徽章（见 `badge_particle_core_spec.md`）→ 扁平柔色环勋章；如保留"高级感"诉求，用 CSS 柔光/微动效替代电弧，**不引入精灵贴图**以维持原"0 粒子成本"目标。
