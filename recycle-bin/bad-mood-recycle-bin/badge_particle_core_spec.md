# 徽章弹窗 VFX 技术规格 —— 粒子残核（参考实现）

> 角色：TechnicalArtist ｜ 项目：坏情绪回收站（微信小程序）
> 本文是 7 枚徽章中**第一枚落地实现**的规格书，其余 6 枚以同一模板补齐。

## 一、效果定义（视觉 → 技术翻译）

| 视觉诉求 | 技术实现 | 预算影响 |
|----------|----------|----------|
| 半透明玻璃感粒子凝聚体 | CSS 多层径向渐变 + inset 高光 + `backdrop-filter: blur(2px)` 微模糊；内部粒子由 canvas 绘制 | 玻璃体 0 粒子成本；内部凝聚粒子计入粒子预算 |
| 周围薄荷绿光晕 | 双层反向旋转 `conic-gradient` 光带，`screen` 混合 + `blur`，纯 GPU 合成 | **0 粒子**，仅 2 个合成层，移动端友好 |
| 蓝绿色电弧闪电环绕 | 单 canvas，`globalCompositeOperation='lighter'` 叠加绘制抖动折线 | 计入电弧预算 |
| 深色半透明遮罩，适合做弹窗 | 全屏 `rgba(5,8,12,.78)` + `backdrop-filter: blur(6px)` | 1 个遮罩层 |

## 二、性能预算（弹窗为瞬时 VFX，按单屏峰值计）

| 资源 | 移动端 | PC / 中端 | 上限依据 |
|------|--------|-----------|----------|
| 内部凝聚粒子 | 36 | 70 | 小程序 canvas 同屏粒子，移动端 ≤500 总预算的 7% |
| 蓝绿电弧（并发） | 6 | 10 | 每条弧 10–16 段，重绘开销随段数线性增长 |
| 叠加混合层（overdraw） | 3 | 4 | 玻璃体 + 光晕×2 + canvas；移动端 ≤3 临界点 |
| 着色器复杂度 | 仅 CSS 渐变 + canvas 直线 | 同上 | 无逐像素光照，移动端安全 |
| 预估单帧耗时 | ~1.6 ms | ~1.0 ms | 触发瞬间峰值，非持续；关闭后停 RAF |

**关键决策**：光晕用 CSS conic 渐变而非粒子，是这枚徽章"省出预算"的核心——把粒子额度全部留给电弧和凝聚体，保证打击感。

## 三、资产交接协议（美术开工前必读）

- 玻璃体无需建模，纯 CSS/Shader 实现；如需 3D 网格版本（Unity/Godot），LOD0 ≤ 1,200 tris，无皮材。
- 电弧与粒子**不依赖贴图**：用程序化折线 + 径向渐变光点，避免引入 256×256 精灵图（省一张 draw call 与压缩体积）。
- 颜色规范：薄荷绿 `hsla(158,90%,75%)`，蓝绿电弧 `rgba(120,235,215)` / 内芯 `rgba(225,255,248)`。

## 六、静态徽章图：3D 立体电弧管线

需求：周围电弧闪电要有**立体感**（不是平贴的细线）。落地为可复用的离线管线。

**分工**
- **有机形体交给 AI**：玻璃凝聚体（泡泡簇 + 粉金内光 + 星点）用图像生成，纯白底输出。
- **物理感交给程序**：电弧完全程序化生成——AI 画不准 3D 纵深关系。

**管线步骤**
1. **白底生成**：AI 只出玻璃核心（提示词明确排除闪电），纯白背景。
2. **抠像**：软 alpha（饱和度 / 暗部）→ **内部填洞**（洪泛填外部，内部白色高光区强补 `alpha=1`）→ 椭圆盘不透明实体 + 外缘柔衰。
3. **3D 电弧**：球面上取**受控倾斜轨道**（法线与 z 轴夹角 46–62°，保证前/后穿越又不会被投影拉成直线）→ 加**切向抖动**（去掉径向分量，半径稳定）+ **2–4 个尖峰** → 电击形；正交投影保留 z。
4. **按 z 符号分段**：每条弧切成"核心前 / 核心后"若干段 → 后段先画（被核心遮挡），前段后画（压在核心上）。
5. **SDF 圆柱截面着色（关键）**：对每段做有符号距离场——
   - 截面 `shade = sqrt(1 - (d/w)²)`
   - 白热芯 `shade^3.2` ｜ 琥珀管身 `shade` ｜ 侧向高光 `exp(-((perp/w + 0.34)/0.26)²)`
   → 读成真正的**发光圆柱**，而非扁线。
6. **深度亮度**：正面弧 `0.62 + 0.38·(z/z_max)`（近观者亮）；背面弧整体 `dim≈0.72` 且越远越暗。
7. **接触阴影 + 光溢出**：前弧在核心上投下偏移模糊阴影（×0.82）并加暖色 bleed → "压在玻璃上"的立体读感。
8. **合成**：全程 **预乘 alpha** + **2×2 精确降采样**（避免透明黑边渗色）。顺序：暖光晕 → 后弧 → 核心 → 阴影/溢光 → 前弧。

**锐化档（v5，当前）**——把「柔光发光面条」调成锐利闪电
| 项 | 旧（柔光） | 新（锐利） | 作用 |
|----|-----------|-----------|------|
| 辉光模糊半径 | 7×SS | **3×SS** | 光晕贴住管身，不再糊成团 |
| 管宽 base_w | 6.0 / 4.2 | **4.6 / 3.4** | 削细，露锯齿 |
| 边缘羽化 | ÷1.6 | **÷0.9** | 截面边界变硬 |
| 白热芯指数 | shade^2.6 | **shade^3.2** | 芯更窄更锋利 |
| 走向抖动 | 平滑单峰 | **锯齿 + 2–4 尖峰** | 折线硬朗，非波浪 |
| 采样点数 n | 42 | **28** | 拐点更硬 |
| 末端 taper | 0.22 平头 | **0.07 针尖** | 刺出感 |
| 粗细 | 平滑包络 | **随机脉动 0.62–1.37 × 每条 0.72–1.28** | 主次分明 |
| 暗金描边 | 无 | **rim_k 0.45 / 0.30** | 亮玻璃上的可读性关键 |

**数量档（v6 定稿）**——用户反馈"电弧太多"，从 7 条砍到 **3 条**
| 项 | v5 | **v6（当前）** | 作用 |
|----|----|--------------|------|
| 电弧数量 | 7 条 | **3 条** | 干净，不喧宾夺主 |
| 分叉支线 | 35% 概率 | **已移除** | 上一版过密 |
| 轨道半径 | 0.72–1.02 × rcore | **0.90 / 1.10 / 1.20 × rcore** | 一内两外：内弧掠玻璃正面给遮挡感，外弧绕圈 |
| 弧段跨度 | 100–158° | **150 / 175 / 165°** | 长弧，读作环绕 |
| 管宽 base_w | 4.6 / 3.4 | **5.4 / 4.0** | 砍数量后回粗，保证存在感 |
| 描边 rim_k | — | **0.45 / 0.30** | 亮管从亮玻璃上"抠"出来 |

- **为何要暗金描边**：玻璃本体是亮粉白色，亮金管压在上面几乎被吃掉（视觉上断成碎段）。加一圈
  略宽的暗金 rim（`d ≈ 1.18w`）后，管身边界从亮底上剥离，三弧连续可读。
- **为何一内两外**：参考图里电弧是环绕在徽章外圈（深底高对比）。内弧负责"掠过玻璃正面"的遮挡纵深，
  外弧负责"深色弹窗上高对比环绕"——两者都要，只做一种都会失衡。
- 输出 `images/badge_particle_remnant_3d.png`：821×821 RGBA，四角 alpha=0（真透明）。
- 生成脚本 `gen_badge_3d_arcs.py`，改 `SRC` 指向新核心图即可复用到其余徽章。

**踩坑记录（复用必看）**
- ❌ 直接要"透明背景" → 模型把**棋盘格烘进不透明像素**（导出 RGB、无 alpha）。
- ❌ 绿幕抠像 → 暖色发光体的半透明光晕吃进绿色，压绿 + 色相校正都救不净。
- ❌ RGBA 层用 LANCZOS 缩放 → 透明像素的黑 RGB 渗进边缘，细弧变**炭灰粗条**（应改预乘 + 2×2 均值）。
- ❌ 只用饱和度阈值抠像 → 玻璃内部白高光被判成背景，深底出现**灰斑**（需内部填洞）。
- ❌ 锐化 ≠ 一味削细：管宽砍太狠会「电弱」到看不见 —— 锐化的正解是**提边缘对比 + 收窄亮度梯度**，宽度维持存在感。
- ❌ 轨道倾角过大（法线≈屏幕面）→ 投影椭圆被压扁，弧被拉成**突兀长直线**（限制 theta ≤ 66°）。
