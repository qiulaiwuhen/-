## 关键技术决策
- 光晕用 CSS `conic-gradient` 旋转而非粒子 → 0 粒子成本，把预算全留给电弧与凝聚体。
- 电弧/粒子纯程序化（canvas `lighter` 混合），不引入精灵贴图 → 省 draw call 与压缩体积。
- 移动端上限：36 粒子 / 6 电弧 / 3 层 overdraw；PC：70 / 10 / 4。触发峰值 ~1.6ms，关闭即停 RAF。

## 本轮迭代：电弧立体感（3D 化）
- 需求：周围电弧闪电要有**立体感**，不能是平贴细线。
- 交付：`images/badge_particle_remnant_3d.png`（821×821 RGBA，真透明）—— 电弧改为程序化 3D 轨道 + **SDF 圆柱截面着色**，并做深度分层遮挡。
  - 生成脚本：`gen_badge_3d_arcs.py`（改 `SRC` 即可复用到其余徽章）。
  - 验证页：`preview_v15.html`（5 种底色切换 / 多尺寸 / 细节放大）。

## 立体感的四个来源
1. **圆柱着色**：`shade=sqrt(1-(d/w)²)` 截面 → 白热芯 + 琥珀管身 + 侧向高光。
2. **深度亮度**：正面弧亮、绕到背后的弧按 |z| 衰减（±0.70 dim）。
3. **遮挡分层**：每条弧按 z 切成前/后段，后段被核心挡住、前段压在核心上。
4. **接触阴影 + 光溢出**：前弧在玻璃上投偏移模糊阴影并列暖色 bleed。

## 关键技术决策
- 分工：有机玻璃形体交给 AI 生成；电弧的 3D 纵深交给程序（AI 画不准遮挡关系）。
- 合成全程**预乘 alpha + 2×2 精确降采样**，避免透明黑边把细弧糊成炭灰。
- 抠像加**内部填洞**，避免玻璃白高光被判成背景、深底出现灰斑。

## 本轮迭代：电弧锐化（v5，按用户反馈）
- 反馈：电弧「太假」，要更锐利。原版是「柔光发光面条」——辉光模糊半径 7×SS 把弧糊成一团。
- **定调：锐化 ≠ 削细**。正解是「提边缘对比 + 收窄亮度梯度」，宽度必须维持存在感（曾砍细到看不见，已回补）。
- 具体改动：

| 项 | 旧 | 新 |
|----|----|----|
| 辉光模糊半径 | 7×SS | **3×SS** |
| 辉光强度 | 0.95 | **0.50 / 0.30** |
| 管宽 base_w | 6.0 / 4.2 | **4.6 / 3.4** |
| 边缘羽化 | ÷1.6 | **÷0.9 硬边** |
| 白热芯指数 | shade^2.6 | **shade^3.2** |
| 走向抖动 | 平滑单峰 | **锯齿 + 2–4 尖峰** |
| 采样点数 | 42 | **28**（折线更硬） |
| 分叉支线 | 无 | **35% 概率** |
| 末端 | 0.22 平头 | **0.07 针尖** |
| 粗细 | 平滑包络 | **随机脉动，主次分明** |

- 另修：弧的**起始相位均匀分布**（四面都有弧，不再堆一侧）；轨道倾角限制 ≤ 62°（倾角过大会把弧投影拉成突兀长直线）。
- 交付：更新 `images/badge_particle_remnant_3d.png` + `preview_v16.html`（5 底色 + 锐化参数前后对比 + 4 处细节放大）；规格书第六章已同步「锐化档」表。

## 本轮迭代：电弧数量收敛（v6，按用户反馈）
- 反馈：电弧太多（7 条 + 分叉），读成「闪电网」。要求**保留三两道**。
- 改动：**弧数 7 → 3**，**删除全部分叉支线**；布局改为**一内两外**——
  - 内弧 `0.90 rcore`：掠过玻璃正面，提供遮挡纵深；
  - 外弧 `1.10 / 1.20 rcore`：在深色弹窗遮罩上高对比环绕。
  - 跨度 150/175/165°，管宽回粗到 5.4/4.0（砍数量后补存在感）。
- **关键修复（新坑）**：亮金管压在**亮粉白玻璃**上对比不足、断成碎段。加一圈略宽的**暗金描边**（`d≈1.18·w`，rim_k 前 0.45 / 后 0.30）把管身从亮底剥离 → 三弧连续可读。
- 交付：更新 `images/badge_particle_remnant_3d.png` + `preview_v17.html`；规格书第六章新增「数量档 v6」表与暗金描边说明。
